## Recovered power source reference
Prior implementation: https://github.com/cbw29512/Tab5LASR/blob/af267272eedddc0169c5e1ed4543d6c68c0fa673/firmware/main/tab5_power.c and docs/BATTERY_AND_AI_CONTRACT.md at the same commit. Contract identifies second expander 0x44 P4 idle LOW, P5 HIGH disables quick charging, P7 HIGH commands standard charging, INA226 at 0x41. Official Tab5 Power Manager https://docs.m5stack.com/en/arduino/m5tab5/power uses M5Unified Power_Class. Prior code uses ESP-IDF BSP and must not be blindly copied into Arduino/M5Unified or used to create competing I2C ownership. Verify exact resolved driver revision and initialization before porting. No manual charger writes or recovery override added; physical battery acceptance outstanding.
