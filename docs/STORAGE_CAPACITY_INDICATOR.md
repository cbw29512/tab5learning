# Storage capacity indicator — approved feature direction

Every device reports its measured filesystem capacity, never an assumed card size. Use decimal GB/MB for display, exact uint64 byte counts for checks and transfer planning. State: NotChecked, Unavailable, Normal, Low, Critical. Invalid/failed readings are unavailable, not full or empty; zero free with a valid nonzero total is critical. Warn at <=10% OR <=1 GB free, critical at <=5% OR <=256 MB free. These are initial engineering thresholds, subject to educator and real workload review. Percent displayed rounded down; human-readable capacity truncated, not rounded up. No automatic cleanup, formatting, deletion or write to settings.

Student UX: small noninteractive capacity indicator if layout permits, and plain-language teacher-directed warnings; detailed free/used/total and last checked in Help. Teacher Studio: authorized USB-only readout with device identity, measurement age, package-size estimate, backup status and proposed update fit. Unknown/stale capacity blocks optional package installation, not access to existing lessons. Do not reject actual learner evidence based solely on an estimate or silently discard attempts; actual durable storage failures must be explicit and recoverable.

Candidate optional-content gate: measured fresh capacity, not critical, proposed positive size <= free minus reserved bytes (default 256 MB). Actual installation requires staging/rollback overhead, cluster rounding, independent backup, current capacity recheck and write verification; this estimate alone is not authorization. Never treat a low-space threshold as a deletion policy.

Implementation first slice: portable model and formatter, tests for 16/64/512 GB and invalid/zero/overflow cases; both isolated SD probes show measured summary after mount. Do not add background filesystem scans to the learner yet; mount/ownership, timing, audio/touch latency, removal detection and failure handling must pass before integration. Future normal firmware displays cached readings with age/invalidation and refreshes only through the storage owner (boot/authorized Help refresh/after verified package changes). No device telemetry network or wireless connection. Current teacher/learner normal UI not wired; physical SD write qualification still pending.
