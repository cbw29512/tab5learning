# Competitive design — MVP
Official feature references (reviewed 2026-11-24): Khan Academy Kids https://www.khanacademy.org/kids/teachers (adaptive learning and teacher tools); Microsoft Reading Coach https://support.microsoft.com/en-gb/education/learning-accelerators/getting-started-with-reading-coach (reading feedback); Google Read Along https://support.google.com/readalong/answer/14174515 (assignments and feedback); Quizlet https://quizlet.com/teachers (authoring); Kahoot https://kahoot.com/schools/how-it-works/ (engagement); Seesaw https://help.seesaw.me/hc/en-us/articles/17964278341005-How-to-create-edit-and-assign-Activities-and-Assessments (assignment workflow).
These are benchmarks, not evidence of superiority. No copying of proprietary assets or curriculum. Original Pocket mascot proposed; name/design not cleared for trademark.
Child: one-tap recommended activity, four plain-language subjects, optional mascot and audio guidance, personal achievements, no competitive pressure. Teacher: structured card editor with optional CSV import, preview before save, exception-first review, explicit data freshness, USB-only synchronization. Compare task completion, time, errors, assistance, accessibility and learning retention with representative users; preserve USABILITY_AUDIT gates. No claims of better learning outcomes until measured.
Editor state: authenticated local draft (title, ordered card IDs/front/back) -> validated preview -> explicit save to immutable deck version. Import replaces draft only after confirmation. No assignment or media support in this slice. CSV optional. Draft not persisted until save; warn before leaving.
